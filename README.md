Build instructions:

1. Open Git Bash (after downloading it from https://git-scm.com/install/windows).
2. Create a new folder on your desktop. Name it whatever you'd like
3. Right click the folder and press "Open Git Bash here" (this will make it easier to clone the repository to the correct location)
3. In Git Bash, type "git clone [full repository URL]" (should start with https://"
4. Done! Now you have a fully working java project in your local desktop!*

*Note: this project will not compile due to not having global permissions to access MongoDB from non-local machines.
